# VillagerGacha

司書が欲しいエンチャント本を出すまで、書見台の設置と破壊を自動で繰り返す Fabric Mod です（クライアント専用）。

- 対応: Minecraft 26.3 / Fabric Loader 0.19.5 以上 / Fabric API
- 任意: Mod Menu（一覧から設定画面を開けます）
- 作者: いるかぁぁ（Dolphin-kun）
- ライセンス: MIT

## 使い方

1. 村人（無職）の隣に書見台を置く場所を決め、その場所を見て **R** キー（床を見ればその上、書見台を見ればその場所が登録されます）
2. **N** キーで「欲しい本リスト」を開き、目標を追加
   - エンチャント欄は「修繕」「mending」などで候補が出ます。`*` は「何でも」
   - 最低Lv は `-` / `+` で、そのエンチャントの最大レベルまで。「何でも」は「最大」（エンチャントごとの最大レベル）も選べます
   - 「最安」ON で、そのレベルで出る一番安い値段（2 + 3×Lv、修繕などのトレジャーは 2 倍）の時だけ当たり
   - 「＋ 何でも・最安」で、種類を問わず最安値の本を狙う目標を追加
3. ホットバーに書見台と斧を用意して **J** キーで開始

当たりが出ると止まり、その目標はリストから消えます。動作中は取引画面を表示せず、視点も動かしません。

## キー（変更可）

| キー | 動作 |
|---|---|
| J | 開始 / 停止 / （一時停止中なら）再開 |
| K | 緊急停止（自動再開もキャンセル） |
| R | 書見台の場所を設定 |
| N | 欲しい本リスト |

## 主な機能

- 村人の職業が外れた瞬間に書見台を置き直すので、毎回必ず新しい取引になります
- 書見台が無くなったら待機し、インベントリに入った時点で続きを始めます
- 斧の残り耐久が少なくなったら、壊す前に止まります（設定で変更可）
- 失敗して止まった時は、少し待ってから最初の手順で自動再開します（連続回数に上限あり）
- チャットには本が見つかった時だけ出し、それ以外はホットバーの上と HUD に表示します
- HUD は 6 か所から位置を選べ、大きさも変えられます

## 注意

マルチサーバーでは自動化 Mod が禁止されていることがあります。使う前にサーバーのルールを確認してください。
